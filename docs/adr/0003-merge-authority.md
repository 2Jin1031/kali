# 0003. 머지 권한

상태: 수락됨
날짜: 2026-10-13

## 상황

하네스(Stop 훅, CI, 가드, 리뷰 에이전트)가 실제로 잘못된 변경을 막아주는지 아직 증거가 없다.

## 선택지

- (가) 머지는 전부 사람이
- (나) 보호 경로를 안 건드린 PR은 CI 통과 후 AI가 머지

| 기준 | (가) | (나) |
|---|---|---|
| 하네스가 놓친 문제가 main에 들어갈 위험 | 낮음 | 하네스 품질에 달림 |
| 사람 시간 | 매 PR 확인 | 보호 경로 PR만 |
| 하네스 신뢰 근거 | 쌓는 중 | 필요 |

## 결정

(가) 지금은 머지를 전부 사람이 한다. 조건이 충족되면 (나)로 바꾼다.

## 결과

- 아침에 PR을 확인하고 머지한다
- PR 템플릿 마지막 항목 "전환 조건 체크"로 매번 조건을 확인한다

## 재검토 조건

다음 둘 다 충족되면 (나)로 전환하는 새 ADR을 제안한다.

1. AI PR **10개 연속**, 사람이 코드를 고치지 않고 그대로 머지
2. Stop 훅이나 CI가 실제로 실패를 잡아낸 적 1번 이상 (장치가 작동한다는 증거)
