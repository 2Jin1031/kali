# 0008. 저장소 구조와 공개

상태: 수락됨
날짜: 2026-10-13

## 상황

혼자 + AI로 개발한다. 앱, 인프라(IaC), 결정 기록이 있다. 면접관은 링크로 들어온다.

## 선택지 (구조)

| 기준 | 한 저장소 (모노레포) | app / infra 분리 |
|---|---|---|
| AI가 전체 맥락을 봄 | ○ | △ 저장소를 오가야 함 |
| AI가 인프라를 못 건드리게 막기 | ○ `infra/` 경로 단위 | ○ 저장소 단위 |
| CI | 경로 필터 필요 | 따로 돎 |
| 면접관이 볼 때 | 링크 하나 | 링크 여러 개 |

## 결정

- 한 저장소 `kali`, 공개
- 구조: `app/` (Spring Boot), `infra/` (IaC, 도구는 나중에), `docs/adr/` (확정된 결정)
- 이름은 본명 대신 "칼리". 도메인은 배포 단계에서

## 결과

- 비밀값은 저장소에 두지 않는다 (GitHub Secrets / AWS 파라미터 스토어). Terraform 상태 파일은 저장소 밖
- 계획 문서·블로그 글 원본은 이 저장소에 넣지 않는다
- `infra/`는 보호 경로 (0002)

## 재검토 조건

- 앱이 둘 이상이 되어 CI가 느려질 때 (경로 필터 또는 분리)
