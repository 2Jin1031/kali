# 0002. 권한 세 칸과 보호 경로

상태: 수락됨
날짜: 2026-10-13

## 상황

AI에게 무엇을 혼자 하게 하고 무엇을 막을지 기준이 필요하다. 밤에는 물어볼 사람이 없으므로 "물어보고" 항목은 파일 경로로 바꿔 기계적으로 막아야 한다.

## 선택지 (가드를 어디서 돌리나)

- (가) Claude Code 권한 차단 + 가드는 CI에서만
- (나) 권한 차단 + 가드를 로컬 Stop 훅과 CI 둘 다에서
- (다) 권한 차단만

| 기준 | (가) | (나) | (다) |
|---|---|---|---|
| 우회 경로(쉘로 파일 수정 등)를 결과(diff)로 다시 잡음 | ○ | ○ | ✕ |
| 사람이 인정할 방법(라벨)이 있음 | ○ | ✕ 로컬엔 라벨이 없어 AI가 영영 못 끝냄 | - |
| 역할 구분 | Stop 훅 = 품질, CI 가드 = 규칙 위반 | 섞임 | - |

## 결정

(가). 권한 세 칸:

| AI 혼자 끝까지 | 나한테 물어보고 | 절대 금지 |
|---|---|---|
| 코드 구현, 리팩터링 | 의존성 추가 | main에 머지/push |
| 테스트 작성 | 빌드 설정 | AWS 실제 반영 (`terraform apply` 등) |
| 브랜치·커밋·PR 생성 | CI 설정 | 비밀키, `.env` 접근 |
| ADR 선택지 정리 (선택은 X) | 공개 API 모양 변경 | 검사 규칙을 약하게 바꿔 통과 (테스트 삭제·스킵 포함) |
| DB 마이그레이션 (0004) | ADR 수락·변경 | 수락된 ADR 수정 |
| | 스펙에 없는 도메인 규칙, 설계 선택지가 갈릴 때 | |

보호 경로 ("물어보고" 칸을 파일로):

| 경로 | 항목 |
|---|---|
| `**/build.gradle.kts`, `settings.gradle.kts`, `gradle/` | 의존성, 빌드 설정 |
| `.github/` | CI 설정 (가드 스크립트 포함) |
| `.claude/`, `AGENTS.md`, `CLAUDE.md` | 하네스 자체 |
| `infra/` | AWS |
| `docs/adr/`의 수락된 ADR | 수락된 ADR 수정 금지 |

막는 장치는 두 겹: `.claude/settings.json` deny(시도 자체를 막음) + CI 가드(diff 검사, `@Disabled` 추가·테스트 파일 삭제·보호 경로·수락된 ADR). 그 밖에 GitHub 브랜치 보호(main은 PR + CI 통과), AI 환경에 AWS 키를 주지 않음.

## 결과

- AI는 보호 경로를 고치지 못하고, 필요하면 PR "내가 결정할 것"에 적는다
- 검사 규칙이 틀렸다고 보면 규칙을 고치지 않고 PR에 이유를 적는다
- 이 목록이 AI 머지 전환(0003)의 기준이 된다

## 재검토 조건

- 밤 작업 실행 위치가 정해질 때 (그 환경에서 같은 규칙을 강제하는 방법 추가)
- 보호 경로 때문에 막히는 PR이 반복되는데 매번 사람이 그대로 인정할 때
