# 0004. DB 마이그레이션은 첫 배포 전까지 AI 혼자

상태: 수락됨
날짜: 2026-10-13

## 상황

초기에는 엔티티를 자주 바꿔볼 것이다. 배포 전에는 DB에 잃을 데이터가 없다.

## 선택지

- (가) 첫 배포 전까지 AI 혼자, 이후 "물어보고"
- (나) 처음부터 "물어보고"

| 기준 | (가) | (나) |
|---|---|---|
| 엔티티를 바꿔볼 때 속도 | 빠름 | 매번 확인 대기 |
| 잘못된 마이그레이션 피해 | 배포 전엔 갈아엎으면 됨 | 낮음 |

## 결정

(가). 첫 배포 전까지 DB 마이그레이션은 "AI 혼자 끝까지" 칸에 둔다.

## 결과

- 6A에서 엔티티를 바꿀 때 AI가 마이그레이션까지 같이 바꾼다
- 마이그레이션 도구(Flyway 등)는 아직 없다. 들일 때 의존성 추가라 사람에게 묻는다

## 재검토 조건

- 첫 배포(6B 완료) 또는 실제 글·로그 데이터가 DB에 들어가기 시작할 때 → "물어보고" 칸으로 옮기는 새 ADR
